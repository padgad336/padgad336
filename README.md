## 🚀 What I Work On

### Enterprise Knowledge Platform

Hybrid file-management and knowledge-management platforms supporting:

- Internal file storage with S3-compatible object storage
- Google Drive and OneDrive integration
- Selective file import and scheduled synchronization
- Team workspaces and role-based permissions
- Storage quota management
- RAG ingestion and permission-aware retrieval

### AI and LLM Infrastructure

- LLM Gateway and Model Orchestration
- AI Agents and Tutor Agents
- Retrieval-Augmented Generation

- Local and Cloud LLM integration
- Usage tracking, rate limiting and API key management
- AI observability and security guardrails

- Event-driven systems and background workers

- Docker-based deployment
